求職票 検索支援ツール

求職票の分析結果から、DeliciousWorker 求人検索APIを使って候補者ごとに求人を検索します。

利用にあたって
  • 各求人カードの「求人ページを見る」は DeliciousWorker への出典リンクです。削除しないでください。
  • 給与・条件などのテキストは API が返した内容をそのまま表示しており、このツールでは書き換えていません。
  • カテゴリの例が hall / kitchen / sushi など飲食系であるため、このサイトは飲食・サービス業寄りの求人が中心である可能性があります。医療事務・一般事務系の求職票では該当求人が少ない場合があります。
  • 候補者単位での利用を想定しています。全件一括での連続検索など運営に負荷をかける使い方は避けてください。
  • このファイルを直接ダブルクリックして開く（file://で始まるURL）と、サイト側の設定によっては検索がブロックされることがあります。うまく検索できない場合は、下の「APIの疎通確認」で原因を切り分けてください。
